# Code of Conduct

## Our pledge

This project is intended to be a respectful, educational, and legally safe environment for learning cybersecurity.

Participants and contributors are expected to communicate professionally and focus on defensive security, documentation, and learning.

## Expected behavior

- Be respectful and constructive.
- Keep discussions legal and educational.
- Explain security concepts responsibly.
- Help beginners understand defensive takeaways.
- Avoid sharing real credentials, private data, or harmful payloads.

## Unacceptable behavior

- Harassment or personal attacks.
- Encouraging unauthorized access to real systems.
- Sharing malware, credential theft techniques, persistence mechanisms, or destructive instructions.
- Publishing private information.
- Using this project to target third-party systems.

## Enforcement

Maintainers may remove content, close issues, or block participation when behavior conflicts with the educational and defensive purpose of the project.
