# Contributing

Thank you for your interest in contributing to this educational cybersecurity project.

The goal of this repository is to provide practical, understandable, and legally safe security learning material.

## How to contribute

Useful contributions include:

- improving documentation;
- adding setup instructions;
- adding comments to security-sensitive code;
- documenting intended vulnerabilities;
- fixing accidental vulnerabilities;
- adding tests;
- improving PHP code quality;
- creating educational tasks and writeups;
- improving project structure.

## Before submitting a pull request

Please make sure that your change:

- has a clear educational or maintenance purpose;
- does not introduce real-world harmful functionality;
- does not include malware, credential theft, persistence, or unauthorized access tooling;
- does not include real credentials, tokens, private keys, or personal data;
- clearly marks intentionally vulnerable code as educational;
- improves safety, clarity, or maintainability.

## Pull request checklist

- [ ] The change has a clear description.
- [ ] Security-sensitive behavior is documented.
- [ ] No secrets or personal data are included.
- [ ] The code is suitable for educational and defensive use.
- [ ] The documentation is updated if needed.
- [ ] The change does not encourage illegal activity.

## Code style

Prefer simple, readable code and clear comments. This project is intended for learners, so understandability is more important than cleverness.

## Issues

When opening an issue, please include:

- what you expected to happen;
- what actually happened;
- steps to reproduce;
- screenshots or logs if useful;
- environment details if relevant.

## Security issues

Please read [SECURITY.md](SECURITY.md) before reporting security issues.
