# Marlin Exam Level 3

**Marlin Exam Level 3** is an open-source educational cybersecurity project focused on practical web security, PHP application security, and CTF-style learning.

The project is maintained as a hands-on training resource for learners who want to understand how web applications can fail, how insecure patterns appear in real code, and how to review, document, and improve application security.

> ⚠️ This project is intended for educational and defensive security purposes only. Do not deploy it in production environments.

## Purpose

This repository is designed to support:

- practical web security learning;
- PHP security review exercises;
- CTF-style tasks and guided vulnerability analysis;
- secure coding practice;
- documentation of common web application weaknesses;
- training for students and beginner information security specialists.

## Maintainer background

The project is maintained by a security-focused maintainer with a background in:

- Computer Security bachelor's degree;

- Linux server administration;

- anti-cheat and abuse-prevention systems;

## Project status

The repository is being updated and reorganized to make it more useful as an open-source cybersecurity education project.

Current priorities:

- improve documentation;
- separate intentionally vulnerable training examples from accidental security issues;
- add setup instructions;
- add safer defaults;
- add tests and review checklists;
- improve maintainability for learners and contributors.

## Security and educational scope

Some parts of this project may contain intentionally vulnerable or insecure patterns for learning purposes.

Intended training examples should be clearly documented. Accidental vulnerabilities, unsafe defaults, or unclear behavior should be reported and fixed.

See [SECURITY.md](SECURITY.md) for details.
