# Project Scope

## What this project is

This project is an educational cybersecurity repository focused on practical web security, PHP application security, and CTF-style learning.

It is intended for:

- students;
- beginner information security specialists;
- CTF learners;
- teachers and mentors;
- developers learning secure coding basics.

## What this project is not

This project is not intended to be:

- a production-ready application;
- an offensive hacking toolkit;
- malware;
- a credential theft tool;
- a tool for unauthorized access;
- a replacement for professional security review.

## Allowed educational topics

The project may include defensive explanations of:

- input validation;
- authentication and authorization mistakes;
- SQL injection;
- cross-site scripting;
- insecure file upload;
- session security;
- insecure configuration;
- logging and monitoring;
- secure coding practices.

## Safety principles

- Keep all examples legal and educational.
- Do not include real credentials or private data.
- Clearly mark intentionally vulnerable examples.
- Prefer local lab environments.
- Do not encourage unauthorized testing.
- Focus on understanding, prevention, and remediation.
