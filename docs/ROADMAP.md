# Roadmap

This roadmap describes the planned direction for the project as an open-source cybersecurity education repository.

## Short-term goals

- Improve README and setup instructions.
- Document the educational purpose of the project.
- Identify intentionally vulnerable examples.
- Separate intended training vulnerabilities from accidental issues.
- Add comments to security-sensitive PHP code.
- Add basic examples and learner notes.

## Medium-term goals

- Add Docker-based local setup.
- Add example CTF-style tasks.
- Add writeups for defensive learning.
- Add automated checks where practical.
- Add basic test coverage.
- Improve project structure.

## Long-term goals

- Turn the repository into a small practical web security training lab.
- Support classroom and self-study use.
- Add guided lessons for common web vulnerabilities.
- Improve maintainability for contributors.
- Build a safer and clearer open-source security education resource.
